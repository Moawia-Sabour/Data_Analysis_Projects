# 🏢 HR Employee Attrition & Retention Analysis

An exploratory data analysis (EDA) project in Python investigating the core drivers of employee turnover and attrition using statistical summaries and visual analytics.

## 📌 Project Overview
Employee turnover poses significant costs and operational disruptions to organizations. This project analyzes an HR dataset of **1,470 employee records** across **35 distinct workplace attributes** to identify key factors influencing employee departure, such as age dynamics, salary levels, tenure, and work-life balance.

## 🔑 Key Findings
- **Age Dynamics:** Employees who left the organization (*Attrition = Yes*, count: 237) had a lower mean age of **33.6 years** compared to **37.6 years** for retained employees (*Attrition = No*, count: 1,233).
- **Tenure & Turnover:** Higher turnover rates were observed among early-career employees with shorter tenure at the company.

## 🛠️ Tech Stack & Libraries
- **Language:** Python 3.x
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `seaborn`, `matplotlib`
