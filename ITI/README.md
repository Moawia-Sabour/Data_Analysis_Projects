# 🎓 ITI Institutional Database Querying & Management

A comprehensive SQL repository containing relational queries, joins, and database operations structured around the ITI (Information Technology Institute) educational database schema.

## 📌 Project Overview
This project demonstrates proficiency in querying relational schemas representing higher education and institutional data structures (Instructors, Departments, Courses, and Student Enrollments).

## 🔑 Key Analysis & Implementation
- **Complex Multi-Table JOINs:** Querying relationships across students, courses, topics, and instructor departments.
- **Subqueries & Conditional Rules:** Extracting non-null records, filtering performance brackets, and organizing course assignments.
