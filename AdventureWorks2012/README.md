# 🛒 AdventureWorks2012 SQL Database Analytics

An enterprise SQL project focused on complex data querying, analytical window functions, data transformation, and schema archiving using the Microsoft **AdventureWorks2012** sample database.

## 📌 Project Overview
This repository contains a structured suite of T-SQL queries written to extract operational metrics, sales distributions, and employee compensation statistics from the enterprise relational database **AdventureWorks2012**.

## 🔑 Key SQL Concepts & Highlights
- **Analytical Window Functions:** Utilized `DENSE_RANK()`, `ROW_NUMBER()`, and `PARTITION BY` to determine top salary tiers per department.
- **Aggregations & Grouping:** Calculated long-term financial performance metrics across historical transaction logs (`2001–2014`).
- **Data Archiving (DDL/DML):** Created structured archive tables (`store_Archive`) to handle data retention routines.
